# 最终19款 LUT 清单

## 用户已确认的菜单命名

柯达统一用 `Koda`（Kodak缩写），富士统一用 `Fuji`；下面19个推荐槽位名均唯一、1–12个可打印ASCII字符，无首尾空格。`P2`表示迫冲两档。Amber、Fade、BW400不编造品牌。

这些是填写到Origin“名称”栏的建议，不是自动导入的软件工程配置。完整胶片名/配方仍由清单和来源记录保留。LUT及PNG文件名不随菜单名改变。
